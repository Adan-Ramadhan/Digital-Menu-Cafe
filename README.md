# ☕ Cafe Menu

Website menu digital untuk cafe yang dibuat menggunakan Next.js.

Project ini dibuat sebagai latihan frontend development dengan fokus pada pembuatan UI yang responsif, reusable component, serta pengelolaan data menu secara dinamis.

## 🚀 Demo

[Live Demo](https://digital-menu-cafe-eight.vercel.app/)

## ✨ Fitur

- Tampilan menu cafe yang responsif
- Filter menu berdasarkan kategori
- Menampilkan menu best seller
- Rendering menu berdasarkan data JSON
- Reusable React components
- Responsive layout untuk mobile, tablet, dan desktop

## 🛠️ Teknologi

- Next.js
- TypeScript
- Tailwind CSS
